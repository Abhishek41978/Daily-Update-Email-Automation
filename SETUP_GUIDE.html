✅ Setup Checklist
  • Extract project folder and open terminal inside it
  • Run npm install
  • Copy .env.example → .env
  • Get Bitbucket API Token (see Step 1 below)
  • Fill BITBUCKET_EMAIL and BITBUCKET_API_TOKEN in .env
  • Get Gmail App Password (see Step 2 below)
  • Fill GMAIL_APP_PASSWORD in .env
  • Create Telegram bot (see Step 3 below)
  • Fill TELEGRAM_BOT_TOKEN in .env
  • Run npm test — all checks green
  • Run npm run send — verify email received
  • Install PM2: npm install -g pm2
  • Start with PM2: npm run pm2
  • Enable PM2 on boot: pm2 startup then pm2 save
  • Send /sendmail to your Telegram bot — verify it works
1️⃣ Bitbucket API Token
1

Go to Bitbucket Settings

Visit bitbucket.org → Click your avatar (top right) → Personal Settings → API tokens

2

Create API Token

Click Create API token. Label: daily-task-report

3

Select Permissions

Grant read access for repositories, issues, and pull requests needed by this report.

4

Copy the token

It is shown only once. Paste it into .env as BITBUCKET_API_TOKEN, and set BITBUCKET_EMAIL to the Atlassian account email that owns the token.

2️⃣ Gmail App Password
Gmail App Passwords require 2-Step Verification to be enabled on your Google account.
1

Enable 2-Step Verification

Go to myaccount.google.com → Security → 2-Step Verification → Turn on

2

Create App Password

Go to myaccount.google.com/apppasswords → App: Mail → Device: Other → type daily-report → Generate

3

Copy 16-character password

Paste it (without spaces) into .env as GMAIL_APP_PASSWORD

If abhishekr@ascendcap.in is a Google Workspace account, an admin may need to allow App Passwords or less secure app access.
3️⃣ Telegram Bot Setup
1

Create a bot via BotFather

Open Telegram → Search @BotFather → Send /newbot

2

Choose name and username

Name: Ascend Task Report   Username: ascend_taskreport_bot (must end in _bot)

3

Copy the token

BotFather gives you a token like 123456:ABCdef.... Paste it as TELEGRAM_BOT_TOKEN

4

Get your Chat ID

Start the bot, send any message, then visit:
https://api.telegram.org/bot<TOKEN>/getUpdates
Find chat.id in the response and set it as TELEGRAM_CHAT_ID

5

Available bot commands

/sendmail — Send today's report now
/status — Check if report was sent today
/help — Show all commands

🚀 PM2 Commands Reference
npm install -g pm2          # Install PM2 globally
npm run pm2                 # Start the app
pm2 status                  # View running processes
pm2 logs daily-task-report  # View live logs
pm2 restart daily-task-report
pm2 stop daily-task-report
pm2 startup                 # Auto-start on server reboot
pm2 save                    # Save current processes
